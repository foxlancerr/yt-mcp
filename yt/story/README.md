# yt/story/ — Story Pipeline Output

One folder per idea, one `story.md` per folder. Created by the `story-pipeline` skill.

```
yt/story/<idea-title-name>/story.md
  ├─ 1. Research summary (niche fit, trend numbers, competitor proof, the gap)
  ├─ 2. Script (full narration, beat taxonomy, [FILL] slots + harvest checklist)
  ├─ 3. Storyboard grid (20s panels, 5 columns)
  ├─ 4. Visual prompt timeline (per-panel prompts, camera, dopamine beats)
  ├─ 5. Titles (primary + 2 alternates, 30–40 chars)
  ├─ 6. Thumbnail text (2 words, 3 options)
  ├─ 7. Metadata package (description, hashtags, keywords, tags)
  └─ 8. Policy check log
```

Nothing here is uploaded or scheduled automatically — publishing needs
explicit user confirmation (AGENTS.md §4.5).
