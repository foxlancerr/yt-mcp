## Honest note on value

Comments do **not** meaningfully lift search ranking — YouTube doesn't index comment
text for discovery. What these actually buy you:

1. A **pinned comment** that sits under the video with a keyword + a question
   (pinning is still a manual Studio click — 13 already waiting).
2. A small engagement signal on videos that currently have 0 comments.
3. A reason for the next viewer to type something, which is what the algorithm
   reads (comment count, not comment words).

If you want ranking, the description/tags work from yesterday does more. This is
engagement hygiene, not SEO.
